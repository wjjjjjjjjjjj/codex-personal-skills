# 大理州政协式公文方案版式

用户提到“公文格式”“仿宋字体”“政府正式呈报材料”“大理州政协那套格式”或同等要求时使用本规则。

## 1. 适用边界

这是本用户约定的正式公文式方案版式基线，不自动宣称严格符合某一国家机关公文标准。用户提供客户模板、红头文件样张或明确格式规范时，以客户要求为最高优先级。

公文版式只决定字体、字号、行距、颜色和表格风格，不自动决定方案必须是四页。仅当项目属于小型正式呈报材料时，才复用大理州政协“四页正式汇报稿”的篇幅和结构。

## 2. 默认版式

- 文档标题：方正小标宋。
- 一级标题：黑体。
- 二级标题：楷体。
- 正文：仿宋。
- 正文字号：16 磅。
- 正文行距：固定值 32 磅。
- 整体颜色：黑白，不使用安铂蓝橙企业配色。
- 表格：仅在投资估算、实施计划或确需行列对比时使用；采用简洁细线表格，不使用彩色底纹和装饰性卡片。

三级及以下标题、页边距、段前段后、页码、落款和日期如有客户模板则服从模板；没有明确要求时，保持正式、克制、层级清晰，不自行声称符合特定标准条款。

## 3. 内容与视觉分离

- 内容口径优先使用安铂现有产品和已验证功能。
- 视觉样式服从客户指定公文格式，不套用安铂企业 VI。
- 成稿直接呈现客户业务、建设内容、投资和实施安排，不说明内部使用了安铂功能清单、知识库或白皮书。

## 4. 字体处理

生成文档前检查方正小标宋、黑体、楷体和仿宋是否可用。字体缺失时：

1. 不静默替换。
2. 优先查找客户模板中实际使用的字体。
3. 向用户说明缺失字体和拟采用的等效字体。
4. 替换后重新渲染全篇，检查标题宽度、换行和分页变化。

## 5. 交付检查

- 标题、一级标题、二级标题和正文是否使用正确字体。
- 正文是否为 16 磅、固定 32 磅行距。
- 是否残留蓝橙配色、彩色卡片或宣传册式装饰。
- 表格是否仅在必要位置使用细线黑白样式。
- 是否存在字体替换、乱码、标题换行、孤行、空白页或表格跨页异常。
- 是否逐页渲染并检查全部页面。
