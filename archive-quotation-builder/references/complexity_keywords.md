# 功能复杂度关键词表

用于人工或上游提取流程为 `quotation_config.json` 的叶子功能建议权重。关键词只提供相对复杂度初值，不证明市场价格、工期或人员投入；用户确认的显式权重优先。

---

## 权重 3：高复杂度（核心技术功能）

这类功能涉及算法实现、系统集成、或复杂数据处理，通常需要专项技术投入。

```
AI, 人工智能, 智能, 算法, 模型, 识别, 预测, 分析, 挖掘,
大数据, OCR, 全文检索, 向量, 语义, 机器学习, 深度学习,
接口, 集成, 对接, 同步, 推送, 自动, 工作流引擎,
数据治理, 元数据, 血缘, 图谱, 可视化, 图表, 仪表,
安全, 加密, 脱敏, 区块链, 存证, 鉴定, 格式转换
```

---

## 权重 2：中等复杂度（流程与管理功能）

这类功能涉及业务流程、多角色协作、或批量数据操作，实现难度适中。

```
审核, 审批, 流程, 权限, 授权, 角色, 配置, 设置,
统计, 报表, 汇总, 导入, 导出, 批量, 上传, 下载,
通知, 消息, 提醒, 日志, 监控, 告警, 巡检,
分类, 标引, 著录, 整理, 组卷, 归档
```

---

## 权重 1：基础功能（CRUD）

标准增删改查操作，技术实现标准化程度高，开发成本低。

- 查看、新增、编辑、修改、删除、预览等未匹配到上述关键词的功能

---

## 使用说明

- 关键词可在功能名称、功能描述和操作说明中查找
- 优先匹配权重3，其次权重2，未命中则为权重1
- 关键词区分中英文，英文大小写不敏感
- 同一系统的全部叶子功能按 `该项权重 / 系统叶子项总权重` 一次分配，不按功能组行数预切预算
- 一个关键词只归属一个等级；“鉴定”按高复杂度处理，不同时出现在中复杂度
