# 报价清单样式规范

样式优先级：招标模板或暗标要求 > 用户明确要求 > 中性报价默认 > 安铂品牌。只有用户明确要求安铂品牌，且不与招标模板或暗标冲突时，才使用下列蓝橙色值。

---

## 颜色体系

| 变量名 | 色值 | 用途 |
|--------|------|------|
| FILL_HEADER | `#003A6B` | 第一行表头背景（深蓝） |
| FILL_CHAPTER | `#004D85` | 章节/系统名称行背景（中蓝） |
| FILL_ODD | `#FFFFFF` | 奇数数据行背景（白） |
| FILL_EVEN | `#F0F6FB` | 偶数数据行背景（浅蓝灰） |
| FONT_PRICE | `#F47920` | 系统总价金额（橙色，加粗） |
| FONT_ROW_PRICE | `#1A7A3E` | 行级分项报价（绿色） |
| FONT_HEADER/CHAPTER | `#FFFFFF` | 表头/章节行文字（白色） |
| FONT_DATA | `#1E293B` | 正文数据文字（深灰近黑） |
| BORDER | `#C8D8E8` | 单元格边框（浅蓝灰） |

---

## 字体

统一使用 **微软雅黑（Microsoft YaHei）**：
- 表头/章节行：size=11-12，bold=True，color=FFFFFF
- 正文数据：size=10，color=1E293B
- 系统总价：size=11，bold=True，color=F47920
- 行级报价：size=9，color=1A7A3E

---

## 列宽配置

| 列 | 宽度 | 说明 |
|----|------|------|
| A | 8 | 序号 |
| B | 22 | 功能模块名称 |
| C | 22 | 子功能 |
| D | 50 | 功能描述（宽，自动换行） |
| E | 22 | 功能点 |
| F | 22 | 子功能点 |
| G | 45 | 操作/功能说明 |
| H | 14 | 报价（万元） |

---

## 行高配置

- 表头行：24pt
- 章节（系统名称）行：28pt
- 数据行（D列内容≤30字）：32pt
- 数据行（D列内容>30字）：48pt

---

## 章节行处理

每个系统名称行（"一、XXX系统"所在行）：
1. 合并 A:G 列，让系统名称完整横向展示
2. H 列独立，显示系统总价（橙色字体）
3. 背景色 `#004D85`，文字白色，字号12加粗
4. 对齐：水平左对齐（缩进1），垂直居中

---

## 对齐规则

- 表头行：水平居中 + 垂直居中 + 自动换行
- 章节行：水平左对齐（indent=1）+ 垂直居中
- D列数据：水平左对齐 + **顶部**垂直对齐 + 自动换行（内容长，需顶部对齐）
- 其他数据列：水平左对齐 + 垂直居中 + 自动换行
- 报价列（H）：水平居中 + 垂直居中
