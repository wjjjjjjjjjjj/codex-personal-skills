# 图文来源 PDF 与多模态智能编研规范

## 1. 适用范围

当任务要求以下任一内容时使用本规范：

- 扩充演示 PDF 的正文和业务语境。
- 在 PDF 中加入照片、插图、流程图、统计图或截图。
- 从来源 PDF 中抽取图片并用于编研。
- 生成图文并茂的专题报告、年鉴、验收总结或汇报材料。

## 2. 图文来源 PDF 的内容结构

单份 PDF 通常控制为 2-4 页、800-1800 个可抽取中文字符。根据业务复杂度调整，不为满足数字堆砌空话。

正文至少包含：

1. 文件背景或形成目的。
2. 业务过程、对象或实施情况。
3. 至少一个判断点、状态变化或责任边界。
4. 结果、限制或下一步事项。
5. 一个表格、流程图、趋势图或场景图片。

每个段落必须增加业务信息。禁止通过放大字号、增加空白页、重复同一句话或铺满装饰图片制造“丰富”假象。

关键实体、数字、日期、状态和结论必须出现在可抽取文本层。图片只能补充解释，不能成为唯一事实载体。

## 3. 图片选择层级

按以下优先顺序选择图片：

1. 用户提供且允许使用的图片。
2. 官方公开页面中来源明确、许可边界清楚的图片。
3. 程序化生成的流程图、关系图、时间线、统计图和示意图。
4. 明确标注为演示模拟的生成式场景图。

涉及真实组织、核工业、军工、能源、医疗或其他敏感领域时，不生成可能被误认为真实现场的设施全景、空间布局、工艺路线、网络拓扑、控制界面、人员身份或设备参数。生成式场景图使用通用环境、不可识别人员和无文字屏幕，并在图注中写明“演示模拟示意图，不对应真实设施、人员或参数”。

禁止选用或自动回填：

- 标识、印章、签名、二维码和私人联系方式。
- 无法核验身份的人物正脸。
- 敏感地图、厂区布局、网络拓扑、控制参数和工艺细节。
- 只有装饰作用、与正文没有关系的图片。
- 无法确认来源或授权边界的图片。

## 4. 图片资产与清单

把可复用图片保存到独立 `assets/images/` 目录。为每张图片建立清单，至少包含：

| 字段 | 要求 |
| --- | --- |
| 图片ID | 稳定、唯一，如 `IMG_BY04_P02_01` |
| 文件名 | 与资产目录一致 |
| 图片类型 | 公开照片、生成式场景图、程序化流程图、统计图等 |
| 来源或生成方式 | 页面 URL、用户提供说明或生成提示摘要 |
| 关联材料 | 源 PDF 或业务主题 |
| 图题 | 可直接用于文档的正式图题 |
| 事实边界 | 公开事实、演示模拟、归一化演示值等 |
| 编研候选 | 是/否及理由 |

生成式图片保留最终提示摘要和生成方式。公开图片保留页面标题、URL、访问日期和使用理由。

## 5. PDF 内嵌规则

1. 图片保持原始宽高比，不拉伸、不裁掉关键主体。
2. 图片宽度与正文版心协调，保证打印和屏幕阅读清晰。
3. 图片附近添加图号、图题、图片 ID、来源和事实边界。
4. 图前或图后至少有一段正文说明图片为什么出现、支持什么判断、不能说明什么。
5. 统计图必须保留周期、总量、分母和“演示数据”标识。
6. 流程图只表达通用过程；具体状态和结论仍引用来源文字。
7. 相同图片可以在不同材料中复用，但编研成果中避免重复插入。

推荐图注：

```text
图2 质量问题整改、验证与经验反馈闭环。图片ID：IMG_BY04_P02_01；程序化演示流程图；具体问题状态以整改验证单为准。
```

## 6. 多模态智能编研提示词

编研提示词除角色、目标、输入、结构、禁编、来源和风格外，增加“图片抽取与图文编研要求”，至少包含以下规则：

1. 扫描每份 PDF 的内嵌图片。
2. 生成稳定图片 ID：`IMG-源文件简称-页码-序号`。
3. 记录源文件、页码、原图题、图片类型和事实边界。
4. 对图片执行 OCR 与图像内容识别。
5. 分开记录“图中直接可见内容”和“结合正文可作的审慎解释”。
6. 选择 3-5 张能够直接支撑正文结论且不重复的图片。
7. 使用系统返回的图片 URI 或图片 ID 插入对应章节。
8. 无法取得 URI 或图片 ID 时，输出 `【插图建议】` 占位，禁止伪造路径。
9. 每张图保留图号、图题、源文件、页码/图片 ID、事实类型和插入理由。
10. 图片不得作为唯一证据，相邻正文必须引用可追溯文字事实。
11. 文末输出“插图来源与使用清单”。

推荐回填格式：

```markdown
![图3 档案利用构成](IMG-BY06-02-01)

*图3来源：BY06第2页；演示统计；插入理由：展示23次检索的业务构成。*
```

无可用图片地址时：

```text
【插图建议：档案利用构成；源文件：BY06；页码：2；图片ID：IMG-BY06-02-01；插入理由：展示设备问题追溯和版本核对占比较高】
```

## 7. 质检

### PDF 结构检查

使用：

```powershell
python scripts/validate_visual_pdf_bundle.py <PDF目录> --min-pages 2 --min-chars 800 --min-images 1
```

确认每份 PDF：

- 达到合理正文长度和页数。
- 中文文本层可抽取。
- 至少有一张内嵌图片。
- 关键实体和状态仍能从文字中命中。
- 图注和事实边界可抽取。

### 编研提示词检查

使用：

```powershell
python scripts/validate_multimodal_compilation.py <编研提示词.md>
```

确认提示词具备图片发现、稳定 ID、OCR/图像理解、可见事实与推断分离、图片回填、无 URI 降级、来源清单和敏感内容排除要求。

### 视觉检查

默认渲染全部最终页并逐页目视检查；批量规模确实过大只能抽样时，记录抽样页和未检范围，不得声称全量视觉验收通过。检查：

- 图片未变形、未越界、未遮挡文字。
- 图题和图片 ID 清楚。
- 正文密度合理，没有大段空白或尾页孤行。
- 生成式图片的模拟边界醒目。
- PDF 与独立图片资产一致。
