# 安铂 PPT 品牌与风格边界

本文件只定义视觉意图和品牌令牌。具体对象、布局、模板继承与导出 API 统一遵循当前 `Presentations` Skill。

## 1. 默认品牌令牌

- 结构蓝：`#004D85`
- 深色背景：`#003B66`
- 焦点橙：`#F9904E`
- 页面浅底：`#F8FAFC`
- 正文深灰：`#334155`
- 辅助灰：`#64748B`
- 分隔线：`#CBD5E1`
- 字体：优先 Noto Sans SC；缺失时采用可稳定嵌入或替代的中文无衬线字体，并在 QA 中记录。

橙色用于结论、关键节点和单一视觉焦点，不作为大面积背景。深蓝建立结构，浅灰负责留白和层次。

## 2. 风格路线

### 商务简约（默认）

用于领导决策、客户交流、项目方案和投标答辩。强调结论型标题、少量高价值信息、清晰关系和克制装饰。

### 科技表达

仅在 AI、数据底座、平台架构等主题确有需要时使用。通过深色页面、网格或数据纹理建立氛围，但保持文字对比度和政企业务可信感；不得用炫光掩盖证据不足。

### 扁平信息图

用于流程、治理闭环、实施路径和模块关系。优先表达空间关系，避免将每个要点都变成同权重卡片。

### 客户 VI

- 客户提供模板或参考 PPTX：由 `Presentations` 的模板继承流程主控，本 Skill 不覆盖母版、版式、字体和页脚。
- 客户只提供颜色规范，且用户要求保留安铂内容与版式方法：允许换肤，先记录颜色映射和禁用项。
- 用户明确要求非安铂风格：退出本文件全部视觉规则。

## 3. 构图原则

- 一页只有一个主要视觉焦点；结论、图表、架构、流程、截图或大数字均可成为主角。
- 优先使用一个连贯构图，不把页面拆成大量 UI 卡片、标签和按钮。
- 标题、正文、来源、结论的层级应在缩略图和全尺寸下都清楚。
- 字号下限、模板字号、文本框换行和对象实现遵循 `Presentations`；内容过多时先删减或换版式，不靠缩小字号解决。
- 中英双语标签仅在受众、品牌或材料本身需要时使用，不作为专业感配额。

## 4. 禁止项

- 无来源数字、固定示例结论或历史客户信息残留；
- 连续三页同构卡片；
- 无业务作用的装饰线、装饰图标和大色块；
- 破坏客户 Logo 比例、颜色或安全区；
- 用模板示例替代真实内容判断。
