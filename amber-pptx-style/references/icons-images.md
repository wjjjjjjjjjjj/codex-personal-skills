# 安铂 PPT 图标、图片与 Logo 规则

视觉资产必须帮助理解内容、提供证据或建立必要的品牌识别。没有语义作用的资产宁可不用。

## 1. 资产选择顺序

1. 用户提供并允许使用的产品截图、客户素材和品牌资产；
2. 可追溯的官方或一手公开图片；
3. 经过核验的图片搜索结果；
4. 明确标注为示意的生成图片；
5. 简单图标或几何符号。

先确认版面需要的宽高比、人物或主体朝向和裁切空间，再搜索或生成。不得先下载素材再强行塞版。

## 2. 图标

- 仅在表示类别、动作、状态或导航时使用，不设置“每页必须有图标”的配额。
- 同一页保持同一图标体系、线宽和视觉重量。
- 优先使用当前环境可用且授权明确的图标资源；先发现实际路径，不硬编码个人目录。
- 彩色 emoji 不作为正式政企 PPT 图标。

## 3. 图片与截图

- 截图必须可读，关键区域可用标注或局部放大；不得把无法阅读的全屏截图当作证据。
- 同一图片默认不重复使用，背景图除外。
- 最终稿不得保留空白框、假截图或“产品界面示意图”占位。真实素材缺失时，删除占位或改成清晰标注的概念示意。
- 检查裁切、清晰度、人物比例、边缘和颜色一致性；发现模糊、拉伸或主体被切断时替换素材。

## 4. Logo

- 使用用户或品牌方提供的原始文件；保持比例、安全区和原始颜色。
- 未经授权不灰度化、不重绘、不改色、不叠加特效。
- 客户模板与客户 Logo 规则优先于安铂品牌锚点。

## 5. 来源与安全

- 外部图片和非平凡外部主张按 `Presentations` 要求写入来源记录或演讲者备注。
- 涉及真实人物、现场、设备、地图、工艺和敏感数据时先核验授权与事实边界。
- 生成式图片必须标注为“示意”或“演示模拟”，不得冒充真实客户现场或产品截图。

## 6. 交付检查

- 每张图片都已加载且没有占位残留；
- 每个 Logo 未变形、未越过安全区；
- 图片裁切与页面阅读方向一致；
- 来源与生成方式可追溯；
- 全页渲染后在实际显示尺寸下仍清晰。
