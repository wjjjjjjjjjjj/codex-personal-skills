# 安铂 PPT 图表选型与证据规则

本文件定义图表的沟通任务，不提供特定生成库代码。具体图表 API、对象属性和渲染方式以当前 `Presentations` Skill 为准。

## 1. 先确认数据可用

每张图表先登记：指标、单位、时间范围、样本范围、统计口径、来源、缺失值和是否为测算。没有真实数据时使用明显占位符 `【待填真实数据】`，不得沿用示例百分比、金额或客户数量。

## 2. 图表选型

| 沟通任务 | 首选图表 | 避免 |
|---|---|---|
| 类别比较 | 横向条形图 | 类别过多的饼图 |
| 时间趋势 | 折线图、面积图 | 用柱图表现高频连续时间 |
| 构成占比 | 100% 堆积、环形图 | 过多切片和相近颜色 |
| 目标差距 | 子弹图、目标线条形图 | 只给大数字不展示基准 |
| 双指标关系 | 散点图 | 双轴图制造假相关 |
| 路径转化 | 漏斗或阶段转化图 | 无口径的装饰漏斗 |
| 风险/优先级 | 四象限、气泡图 | 用气泡大小承载不可比较指标 |

## 3. 安铂样式

- 主序列使用结构蓝，唯一重点使用焦点橙；其余序列使用 Slate 灰阶或浅蓝。
- 弱化网格线和边框，保留必要轴、单位、标签和图例。
- 标题写判断，图表下方给一句解读或 SO WHAT；读者不应自行猜结论。
- 不使用 3D、伪渐变、装饰阴影或过多颜色制造“高级感”。

## 4. 复杂图表

组合图、双轴图、雷达图和气泡图只有在指标关系确实需要时使用。必须说明轴、尺度和比较限制；如果一张图需要长篇解释才能避免误读，改用两个简单图或矩阵。

## 5. QA

- 数据与源表总计、排序和单位一致；
- 颜色没有暗示错误的好坏方向；
- 标签、图例、来源和口径在全页渲染后可读；
- 不存在示例数字、历史日期或旧客户名称残留；
- 图表与本页结论一致，没有选择性截断坐标或夸大变化。
