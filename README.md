# Codex Personal Skills

吴健个人使用与维护的 Codex Skill 集合，面向档案信息化售前、投标、演示数据、研究与正式材料生产。

## Included skills

- `amber-pptx-style`：安铂售前及领导汇报 PPT 的内容确认与品牌规范
- `archive-quotation-builder`：档案信息化项目功能级报价与预算对账
- `bid-document-builder`：投标、响应、陪标或磋商文件全流程编写
- `bid-technical-proposal`：技术标、技术响应与评分技术项追踪
- `demo-data-builder`：可验证的合成档案演示数据包
- `doc-token-saver`：大体量文档输入的上下文预算与来源索引
- `markitdown-converter`：本地文件批量规范化为 Markdown
- `presales-consultant-persona`：售前客户需求重构、风险和竞标策略判断
- `presales-proposal-builder`：政企与档案信息化售前方案内容总控
- `research`：多来源综合研究与证据化判断

## Scope

这些 Skill 是个人工作流资产，不代表任何客户、公司或第三方项目的官方发布版本。正式使用时仍需根据当前项目材料、产品能力、采购文件和授权范围进行核验。

## Layout

每个目录通常包含 `SKILL.md`，以及该 Skill 所需的 `references/`、`scripts/`、`agents/` 或 `evals/` 等辅助文件。
